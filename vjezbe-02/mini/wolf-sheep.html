Wolf Sheep Predation: ovce, vukovi i trava

Dvije vrste turtles i trava na parcelama. Brojevi ovaca i vukova osciliraju, a da li neka vrsta izumre, zavisi od parametara i od slučajnosti.

Model iz biblioteke NetLoga, verzija sheep-wolves-grass: pravila, kod u NetLogu i C#, šta se mjeri i rezultat 100 pokretanja (5 uslova × 20).

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Agenti

Dva breeda s energijom i parcele s travom

Ovce i vukovi su turtles iz dva breeda; obje vrste imaju atribut energy. Parcela (patch) je zelena (trava) ili smeđa, a countdown broji tickove do ponovnog rasta trave.

parametar (klizač)zadanoznačenje
initial-number-sheep100ovaca na početku

sheep-gain-from-food4energija iz jedne parcele trave
wolf-gain-from-food20energija iz jedne ovce
sheep-reproduce4 %vjerovatnoća reprodukcije ovce po ticku
wolf-reproduce5 %vjerovatnoća reprodukcije vuka po ticku
  • Svijet ima 51 × 51 = 2601 parcelu i omotava se (torus). Na početku je oko pola parcela zeleno.
  • Početna energija je slučajna: ovca random (2 * sheep-gain-from-food), vuk random (2 * wolf-gain-from-food).

Pravila

Jedan tick: prvo ovce, zatim vukovi, na kraju trava

Kretanje troši jednu jedinicu energije. Ko ima energiju manju od nule, nestaje (die). Reprodukcija dijeli energiju između roditelja i potomka.

1 ovce

  • okret i korak naprijed, energija −1
  • na zelenoj parceli: pojede travu (parcela postaje smeđa), energija +4
  • energija < 0: ovca nestaje
  • s vjerovatnoćom 4 %: potomak
move · eat-grass · death · reproduce-sheep

2 vukovi

  • okret i korak naprijed, energija −1
  • ako je na istoj parceli ovca: pojede jednu (slučajnu), energija +20
  • energija < 0: vuk nestaje
  • s vjerovatnoćom 5 %: potomak
move · eat-sheep · death · reproduce-wolves

3 parcele

  • smeđa parcela smanji countdown za 1
  • kad countdown dođe do 0, parcela postaje zelena, a countdown se vrati na 30
ask patches [ grow-grass ]
NetLogo
to go
  if not any? turtles [ stop ]
  ask sheep [
    move
    set energy energy - 1
    eat-grass
    death
    reproduce-sheep
  ]
  ask wolves [
    move
    set energy energy - 1
    eat-sheep
    death
    reproduce-wolves
  ]
  ask patches [ grow-grass ]
  tick
end
C#
static bool Go()
{
    if (!World.Turtles.Any()) return false;    // stop
    World.Ask(sheep, s =>                      // slučajan red
    {
        s.Move();
        s.Energy -= 1;
        s.EatGrass();
        s.Death();
        if (s.Dead) return;     // die prekida ostatak bloka
        s.ReproduceSheep();
    });
    World.Ask(wolves, w =>
    {
        w.Move(); w.Energy -= 1; w.EatSheep();
        w.Death(); if (w.Dead) return;
        w.ReproduceWolves();
    });
    World.Ask(patches, p => p.GrowGrass());
    World.Tick();
    return true;
}

Kod je skraćen: u originalu se set energy energy - 1, eat-grass i death za ovce izvršavaju samo u verziji sheep-wolves-grass, a i trava raste samo u toj verziji.

Interakcija

Vuk i ovca na istoj parceli: one-of sheep-here

Vuk vidi samo ovce na svojoj parceli. Ako ih nema, one-of vraća nobody (u C# null) i vuk ne dobija energiju u tom ticku.

NetLogo
to eat-sheep  ; procedura vuka
  let prey one-of sheep-here
  if prey != nobody [
    ask prey [ die ]
    set energy energy + wolf-gain-from-food
  ]
end

to eat-grass  ; procedura ovce
  if pcolor = green [     ; parcela ispod ovce
    set pcolor brown
    set energy energy + sheep-gain-from-food
  ]
end

to reproduce-sheep
  if random-float 100 < sheep-reproduce [
    set energy (energy / 2)
    hatch 1 [ rt random-float 360 fd 1 ]
  ]
end
C#
void EatSheep()   // metoda klase Wolf
{
    var prey = PatchHere.Here<Sheep>().OneOf();
    if (prey != null)                 // nobody
    {
        prey.Die();
        Energy += Globals.WolfGainFromFood;
    }
}

void EatGrass()   // metoda klase Sheep
{
    if (Pcolor == Green)              // boja parcele
    {
        Pcolor = Brown;
        Energy += Globals.SheepGainFromFood;
    }
}

void ReproduceSheep()
{
    if (World.RandomFloat(100) < Globals.SheepReproduce)
    {
        Energy /= 2;
        this.Hatch(c => { c.Right(World.RandomFloat(360)); c.Forward(1); });
    }
}
1Turtle čita i mijenja pcolor parcele na kojoj stoji. Ovca koja dođe kasnije u istom ticku vidi travu koju je prethodna već pojela.
2hatch pravi kopiju roditelja (i njegovu energiju), pa potomak dobija pola energije, kao i roditelj.
3Isti model u C# je u materijali/netlogo-kroz-csharp/WolfSheep/, linija uz liniju s originalom.
Mjere

Mjeri se broj ovaca, vukova i parcela s travom u svakom ticku

BehaviorSpace, NetLogo 7.0.4 headless: 5 uslova, po 20 pokretanja, najviše 1000 tickova. Ostale mjere izračunate su iz ta tri broja.

  • ishod do ticka 1000: obje vrste opstale, vukovi izumrli, izumrle obje vrste ili ovaca više od 5000 (tada se pokretanje prekida);
  • tick izumiranja: prvi tick u kojem je broj vukova (ili ovaca) nula;
  • prosjek, najmanja i najveća vrijednost od ticka 100: prvih 100 tickova je prelaz od početnog stanja; računa se samo za pokretanja u kojima obje vrste opstanu;
  • period oscilacija: pomak (u tickovima) na kojem se niz broja ovaca najviše poklapa sam sa sobom, tj. prvi vrh autokorelacije;
  • kašnjenje vukova: pomak s najvećom korelacijom između broja ovaca i kasnijeg broja vukova.

Tumačenje

Oscilacije nastaju iz povratne veze s kašnjenjem

Nijedno pravilo ne opisuje oscilacije. One nastaju iz tri lokalna pravila: hrana daje energiju, kretanje je troši, a reprodukcija zavisi od toga koliko je jedinki živo.

Ciklus

Više ovaca znači više hrane za vukove, pa broj vukova raste. Vukovi zatim smanje broj ovaca, nakon čega vukovi gube energiju i njihov broj opada. Trava ograničava rast ovaca.

Šta je „ravnoteža“ u ovom modelu?

Nije jedno stanje, nego raspon unutar kojeg se brojevi kreću. Tvrdnja o ravnoteži zato navodi mjeru (npr. prosjek od ticka 100), raspon među pokretanjima i broj pokretanja u kojima neka vrsta izumre.
