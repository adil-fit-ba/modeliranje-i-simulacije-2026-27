NetLogo kroz C#: sedam pojmova

Sedam mjesta na kojima se NetLogo ponaša drugačije nego obična petlja u C#. Uz svako mjesto: kod u oba jezika, objašnjenje i rezultat koji je dao NetLogo.

C# kod koristi biblioteku MiniNetLogo iz materijala (World.Ask, Shuffle, Hatch, PatchAt), s istim imenima kao u dijelu „Kod kroz C#“ prezentacije vježbi 2. Svaka brojka je izmjerena u NetLogu 7.0.4 bez prozora (headless).

Pojam 1 · ask

ask obilazi agente slučajnim redom, novim pri svakom pozivu

U C# je ask petlja foreach nad promiješanom kopijom skupa: World.Ask prvo pozove Shuffle().

NetLogo
create-turtles 5
repeat 3 [
  ask turtles [ type who type " " ]
  print ""
]
; npr. 2 4 0 3 1 / 1 0 2 3 4 / 3 0 1 4 2
C# · MiniNetLogo
World.CreateTurtles<Turtle>(5);
for (int i = 0; i < 3; i++)
{
    var red = new List<int>();
    World.Ask(World.Turtles, t => red.Add(t.Who));
    Console.WriteLine(string.Join(" ", red));
}   // Ask: foreach (var a in agents.Shuffle()) { ... }

Šta se desi i zašto. Tri poziva daju tri različita redoslijeda, jer ask prije svakog obilaska ponovo promiješa skup; zato dva pokretanja istog modela daju različite rezultate.

Izmjereno u NetLogu 7.0.4

pokretanja × poziva = redoslijeda za 5 turtles. Različitih je od mogućih (za slučajan red očekuje se oko ).

Red 0 1 2 3 4 (po who) pojavio se put. Turtle 0 je bila prva puta, a očekivano je oko 40.

Pojam 2 · with ili if

with izabere skup prije petlje, if odlučuje u trenutku

Tri crvene turtles; svaka crvena oboji ostale u plavo. Uslov se mijenja tokom petlje, pa dva zapisa daju različit rezultat.

NetLogo
; IF: svaka odluči kada dođe na red
ask turtles [
  if color = red [
    ask other turtles [ set color blue ]
  ]
]
; WITH: prvo izbor, pa ask (tri nove crvene)
ask turtles with [ color = red ] [
  ask other turtles [ set color blue ]
]
C# · MiniNetLogo
// if: provjera u trenutku kada je t na redu
World.Ask(World.Turtles, t =>
{
    if (t.Color == Red)
        World.Ask(World.Turtles.Other(t), o => o.Color = Blue);
});
// with = Where + ToList: skup napravljen prije petlje
World.Ask(World.Turtles.With(t => t.Color == Red), t =>
    World.Ask(World.Turtles.Other(t), o => o.Color = Blue));

Šta se desi i zašto. Kod if prva turtle na redu oboji ostale, pa one kada dođu na red više nisu crvene; kod with su sve tri izabrane prije petlje i izvrše naredbe iako više nisu crvene (asinhrono ažuriranje: agent vidi promjene agenata prije njega).

Izmjereno u NetLogu 7.0.4 · pokretanja

if: izvršenja , crvenih na kraju  ·  with: izvršenja , crvenih . Isto u svakom pokretanju.

Koja turtle ostane crvena zavisi od redoslijeda: who .

LINQ Where bez ToList() provjerava uslov tokom petlje, pa se ponaša kao if, a ne kao with.

Pojam 3 · die

Turtle koja umre prije svog reda se preskače

Deset turtles; svaka koja dođe na red ukloni sve ostale. World.Ask radi nad kopijom skupa i preskače agente s Dead == true.

NetLogo
create-turtles 10
ask turtles [
  ask other turtles [ die ]
]
show count turtles          ; 1
; die odmah završava naredbe te turtle
C# · MiniNetLogo
World.CreateTurtles<Turtle>(10);
World.Ask(World.Turtles, t =>
    World.Ask(World.Turtles.Other(t), o => o.Die()));
// World.Turtles.Count == 1

foreach (var t in World.Turtles) t.Die();
// InvalidOperationException: lista se promijenila
// U C# poslije Die() treba return.

Šta se desi i zašto. Prva turtle na redu ukloni ostalih devet, a ask mrtve turtles preskače, pa blok izvrši samo jedna; obični foreach nad listom koja se mijenja baca InvalidOperationException, zato World.Ask radi nad kopijom (Shuffle).

Izmjereno u NetLogu 7.0.4 · pokretanja

Od turtles preživi ; blok izvrši . Isto u svakom pokretanju.

Preživi ona koja je prva na redu, pa je različita: who .

World.Ask: foreach (var a in agents.Shuffle()) { if (a.Dead) continue; commands(a); }
Pojam 4 · hatch

Turtle izležena tokom ask nije na redu u tom ask

Pet crvenih turtles veličine 2; svaka izleže jednu. Dijete je kopija roditelja s novim who.

NetLogo
create-turtles 5 [ set color red set size 2 ]
ask turtles [ hatch 1 ]
show count turtles                     ; 10
show count turtles with
  [ color = red and size = 2 ]         ; 10
C# · MiniNetLogo
World.CreateTurtles<Turtle>(5, t => { t.Color = Red; t.Size = 2; });
World.Ask(World.Turtles, t => t.Hatch());
// World.Turtles.Count == 10
// Hatch: kopija roditelja (MemberwiseClone),
// isti položaj i Heading, novi Who

Šta se desi i zašto. ask radi nad skupom napravljenim prije petlje, pa na red dođe pet starih turtles, a svako dijete je kopija roditelja (boja, veličina, položaj, heading) s novim who.

Izmjereno u NetLogu 7.0.4 · pokretanja

Na redu , ukupno , crvenih veličine 2: . Svih djece ima isti položaj i heading kao roditelj. Isto u svakom pokretanju.

Petlja for do World.Turtles.Count ne bi završila: svako dijete bi došlo na red i izleglo novo.

Pojam 5 · torus

Svijet je torus: preko ivice se izlazi na suprotnu stranu

Svijet −25..25 je širok 51 parcelu. fd omotava koordinatu, a distance bira kraći put: direktno ili preko ivice.

NetLogo · svijet −25..25, wraps
create-turtles 1 [
  setxy 25.2 0  set heading 90
  fd 1  print xcor                 ; -24.8
]
; turtle 1 u (-25, 0), turtle 2 u (25, 0)
[ distance turtle 2 ] of turtle 1  ; 1
C# · MiniNetLogo
World.ClearAll(-25, 25, -25, 25);
var t = World.CreateTurtles<Turtle>(1)[0];
t.SetXY(25.2, 0); t.Heading = 90;
t.Forward(1);                         // t.X == -24.8
// World.Distance, za svaku osu:
double dx = Math.Abs(x1 - x2);
dx = Math.Min(dx, WorldWidth - dx);   // preko ivice

Šta se desi i zašto. Ivica svijeta nije zid: koordinata izvan [−25,5; 25,5) vraća se sa suprotne strane, pa su tačke x = −25 i x = 25 susjedne (udaljenost 1), a formula bez omotavanja dala bi 26,2 i 50.

Pojam 6 · patch-here

Parcela pxcor pokriva [pxcor − 0,5; pxcor + 0,5)

Tačka 2,5 pripada parceli (patch) 3, a tačka −2,5 parceli −2: polovina ide naviše. C# Math.Round polovinu zaokružuje na paran broj.

NetLogo · svijet −25..25
[ pxcor ] of patch 2.5 0         ; 3
[ pxcor ] of patch -2.5 0        ; -2
ask turtle 0 [
  setxy 2.5 0
  show [ pxcor ] of patch-here   ; 3
]
C# · MiniNetLogo
World.PatchAt(2.5, 0).Pxcor      // 3
World.PatchAt(-2.5, 0).Pxcor     // -2
// u PatchAt:
int px = (int)Math.Floor(WrapX(x) + 0.5);
// zamka:
Math.Round(2.5)                  // 2, a parcela je 3

Šta se desi i zašto. Granica između dvije parcele je na polovini i pripada većoj parceli, što daje Math.Floor(x + 0.5), dok Math.Round(2.5) vraća 2, jer C# polovinu zaokružuje na paran broj.

Izmjereno u NetLogu 7.0.4 · 1 pokretanje (nema slučajnosti)

patch x 0 i patch-here turtle u (x, 0) dali su istu parcelu za svih vrijednosti. Crveno: C# Math.Round daje drugu parcelu (25,5 se omota na −25,5).

U PDF verziji prezentacije za ponavljanje (slajd 39) stajao je kraći zapis (int)Math.Round(X), koji griješi upravo na polovinama. U HTML verziji je ispravljen na Math.Floor(X + 0.5), kao u MiniNetLogu.

Pojam 7 · nobody

nobody je null: one-of iz praznog skupa vraća nobody

Deset turtles, svaka crvena ili plava. Zelene nema, pa one-of nema koga vratiti.

NetLogo
let zelena one-of turtles with [ color = green ]
if zelena != nobody [
  ask zelena [ set color yellow ]
]
; Wolf Sheep: let prey one-of sheep-here
;             if prey != nobody [ ... ]
C# · MiniNetLogo
var zelena = World.Turtles
    .With(t => t.Color == Green).OneOf();
if (zelena != null)
{
    zelena.Color = Yellow;
}
// bez provjere: NullReferenceException

Šta se desi i zašto. one-of iz praznog skupa ne javlja grešku nego vraća nobody, a greška nastaje tek kada se od nobody nešto traži, kao NullReferenceException u C#; zato iza one-of ide provjera != nobody.

Pravilo za čitanje NetLogo koda

Za svaku liniju: ko je ovdje this i nad kojim skupom radi petlja. Pojmovi 1–4 su posljedica istog pravila: ask radi nad kopijom skupa, slučajnim redom, i svaki agent vidi promjene agenata prije njega.
