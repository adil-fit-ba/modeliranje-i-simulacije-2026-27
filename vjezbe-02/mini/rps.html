Rock Paper Scissors: ciklična dominacija

Crvena pobjeđuje zelenu, zelena plavu, a plava crvenu. Nijedna boja ne pobjeđuje trajno, a brzina reprodukcije mijenja obrazac koji nastaje.

Model iz biblioteke NetLoga u kojem su agenti samo parcele (patches): pravila, kod u NetLogu i C#, šta se mjeri i rezultat 30 pokretanja (3 brzine reprodukcije × 10).

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Agenti

Agenti su parcele, a stanje je boja parcele

Model nema turtles. Svaka parcela (patch) je crvena, zelena, plava ili prazna (crna) i djeluje samo na jednu od četiri susjedne parcele (neighbors4).

strelica: od pobjednika prema poraženom
  • Svijet ima 151 × 151 = 22 801 parcelu i omotava se (torus). Na početku je svaka parcela slučajno jedno od četiri stanja (one-of [ red green blue black ]), oko 25 % svakog.
  • Nijedna boja nije najjača: svaka pobjeđuje jednu i gubi od druge.

Agent ne mora biti pokretan

Parcela izvršava kod i mijenja susjednu parcelu, pa je agent iako se ne kreće. U modelu stava „mjesto“ je samo okolina; ovdje je mjesto sam agent.

NetLogo
to setup
  clear-all
  ask patches [
    set pcolor one-of [ red green blue black ]
  ]
  reset-ticks
end

to-report beat? [ target ]
  report (pcolor = red   and [ pcolor ] of target = green) or
         (pcolor = green and [ pcolor ] of target = blue) or
         (pcolor = blue  and [ pcolor ] of target = red)
end
C#
static void Setup()
{
    World.ClearAll(-75, 75, -75, 75);           // 151 × 151
    World.Ask(World.Patches, p =>
        p.Pcolor = World.OneOf(Red, Green, Blue, Black));
    World.ResetTicks();
}

bool Beats(Patch t) =>                         // beat?
       (Pcolor == Red   && t.Pcolor == Green)
    || (Pcolor == Green && t.Pcolor == Blue)
    || (Pcolor == Blue  && t.Pcolor == Red);
Pravila

Tri događaja između parcele i susjeda

Parcela izabere jednu slučajnu susjednu parcelu (one-of neighbors4) i s njom izvrši jedan od tri događaja.

1 zamjena (swap)

Parcele zamijene boje. Tako se „jedinke“ pomjeraju kroz prostor.

swap target

2 reprodukcija

Ako je jedna od dvije parcele prazna, preuzme boju druge. Inače se ništa ne dešava.

reproduce target

3 selekcija

Ako jedna boja pobjeđuje drugu, poražena parcela postaje prazna. Iste boje ili prazno: ništa.

select target
NetLogo
to select [ target ]
  ifelse beat? target [
    ask target [ set pcolor black ]
  ] [
    if [ beat? myself ] of target [
      set pcolor black
    ]
  ]
end

to reproduce [ target ]
  ifelse [ pcolor ] of target = black [
    ask target [ set pcolor [ pcolor ] of myself ]
  ] [
    if pcolor = black [ set pcolor [ pcolor ] of target ]
  ]
end
C#
void Select(Patch target)
{
    if (Beats(target))
        target.Pcolor = Black;
    else if (target.Beats(this))      // [ beat? myself ] of target
        Pcolor = Black;
}

void Reproduce(Patch target)
{
    if (target.Pcolor == Black)
        target.Pcolor = Pcolor;       // [ pcolor ] of myself
    else if (Pcolor == Black)
        Pcolor = target.Pcolor;
}
Vrijeme

Jedan tick: lista događaja slučajnim redom

Model ne kaže „svaka parcela uradi isto“. Prvo se odredi koliko će biti događaja svake vrste, zatim se lista promiješa i svaki događaj izvrši slučajna parcela.

  • Broj događaja jedne vrste je slučajan, s Poissonovom raspodjelom i očekivanjem count patches / 3 × stopa.
  • Stopa je 10 ^ eksponent. Uz sve tri stope 1 (eksponenti 0) prosječno je jedan događaj po parceli u ticku.
  • reproduce-rate-exponent mijenja samo reprodukciju: −1 daje 10 puta rjeđu, a 1 10 puta češću reprodukciju od zadane.
  • Parcela može u istom ticku učestvovati u više događaja ili ni u jednom.

22 801 / 3 ≈ 7600; zamjena i selekcija ostaju na ≈ 7600 događaja po ticku.

NetLogo
to go
  let repetitions count patches / 3
  let events shuffle (sentence
    n-values random-poisson (repetitions * swap-rate)      [ 0 ]
    n-values random-poisson (repetitions * reproduce-rate) [ 1 ]
    n-values random-poisson (repetitions * select-rate)    [ 2 ]
  )
  foreach events [ event ->
    ask one-of patches [
      let target one-of neighbors4
      if event = 0 [ swap target ]
      if event = 1 [ reproduce target ]
      if event = 2 [ select target ]
    ]
  ]
  tick
end
C#
static void Go()
{
    double rep = World.Patches.Count / 3.0;
    var events = new List<int>();
    events.AddRange(Enumerable.Repeat(0, RandomPoisson(rep * SwapRate)));
    events.AddRange(Enumerable.Repeat(1, RandomPoisson(rep * ReproduceRate)));
    events.AddRange(Enumerable.Repeat(2, RandomPoisson(rep * SelectRate)));
    foreach (var e in events.Shuffle())
    {
        var p = (RpsPatch)World.Patches.OneOf();       // ask one-of patches
        var target = (RpsPatch)p.Neighbors4.OneOf();
        if (e == 0) p.Swap(target);
        if (e == 1) p.Reproduce(target);
        if (e == 2) p.Select(target);
    }
    World.Tick();
}
// RandomPoisson nije u MiniNetLogo; random-poisson u NetLogu
Mjere

Mjeri se broj parcela svake boje u svakom ticku

BehaviorSpace, NetLogo 7.0.4 headless: tri vrijednosti reproduce-rate-exponent (−1, 0, 1), po 10 pokretanja, 600 tickova; ostale stope zadane.

  • opstanak: da li sve tri boje postoje u ticku 600 i koliki je najmanji broj parcela neke boje u cijelom pokretanju;
  • udio praznih parcela, prosjek od ticka 100 (prvih 100 tickova je prelaz od slučajnog početka);
  • amplituda: standardna devijacija broja parcela jedne boje od ticka 100, podijeljena prosjekom te boje (relativno rasipanje), i najveći udio jedne boje među obojenim parcelama;
  • prostorni obrazac: u ticku 600, među obojenim susjedima obojene parcele, udio susjeda iste boje (10 novih pokretanja po uslovu).

Zašto relativno rasipanje

Uz rjeđu reprodukciju ima više praznih parcela, pa je i manje obojenih. Isto rasipanje u broju parcela tada je veći dio populacije.

NetLogo · BehaviorSpace
; Vary: reproduce-rate-exponent [ -1 0 1 ]
; Repetitions 10, Time limit 600, every step
count patches with [ pcolor = red ]
count patches with [ pcolor = green ]
count patches with [ pcolor = blue ]
count patches with [ pcolor = black ]

; na kraju pokretanja: udio susjeda iste boje
mean [ count neighbors4 with [ pcolor = [ pcolor ] of myself ]
       / count neighbors4 with [ pcolor != black ] ]
  of patches with [ pcolor != black and
                    any? neighbors4 with [ pcolor != black ] ]
C#
int Count(Color c) => World.Patches.Count(p => p.Pcolor == c);

double IstaBoja() => World.Patches
    .Where(p => p.Pcolor != Black && p.Neighbors4.Any(n => n.Pcolor != Black))
    .Average(p => p.Neighbors4.Count(n => n.Pcolor == p.Pcolor)
             / (double)p.Neighbors4.Count(n => n.Pcolor != Black));

Ciklična dominacija

Crvena smanjuje zelenu, pa plava (koju zelena pobjeđuje) dobija prostor, a plava zatim smanjuje crvenu. Nijedno pravilo ne kaže „održi ravnotežu“; ona nastaje iz kruga.

beat? · select

Lokalnost

Parcela djeluje samo na susjednu. Zato se boje grupišu u oblasti, a granice oblasti se pomjeraju; na cijelom svijetu sve tri boje postoje istovremeno.

Gdje se javlja ciklična dominacija

Model se oslanja na radove o cikličnoj kompeticiji u biologiji (Reichenbach, Mobilia i Frey, 2007 i 2008; navedeni u Info kartici modela). Za temu iz društvenih nauka treba pokazati da u njoj zaista postoji krug, a ne hijerarhija: ko pobjeđuje koga i šta znači „prazno“.

Šta isprobati

  • Pokrenite model s reproduce-rate-exponent −1, 0 i 1. Opišite razliku u slici svijeta poslije 600 tickova.
  • Postavite swap-rate-exponent na 1 (brže kretanje). Prije pokretanja zapišite očekivanje: hoće li oblasti biti veće ili manje?
  • U BehaviorSpace ponovite jedan uslov 10 puta i zapišite najmanji broj parcela neke boje u svakom pokretanju.
  • Info kartica modela pita: postoje li postavke parametara pri kojima jedna boja nestane? Šta se tada dešava s druge dvije?
