Segregation: blaga preferencija, jaka podjela

Svako traži samo 30% susjeda svoje boje, a na kraju je oko 75% susjeda iste boje. Kada je zahtjev prevelik, grad se više ne smiri.

Schellingov model iz biblioteke NetLoga korak po korak: pravila, kod u NetLogu i C#, šta se mjeri, rezultati iz NetLoga i tumačenje.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Pravila

Zadovoljna je turtle kojoj je dovoljno susjeda iste boje

Turtle gleda osam susjednih parcela (patches). Ako je među susjedima manje od %-similar-wanted posto njene boje, seli se. Pomjerite klizače.

  • Grad: 51 × 51 parcela, svijet se omotava; density = 95%, pa je oko 5% parcela prazno. Boja je slučajna, pola-pola.
  • Selidba: nezadovoljna turtle se okrene za slučajan ugao i skoči do 10 parcela daleko; ponavlja dok ne nađe praznu parcelu.
  • Kraj: kada su sve turtles zadovoljne, model staje. Turtle bez susjeda je zadovoljna (0 ≥ 0).
happy? = similar-nearby ≥ %-similar-wanted × total-nearby / 100
Kod

Tri procedure: go, find-new-spot i update-turtles

Kod je iz modela u biblioteci NetLoga (Segregation, Uri Wilensky, 1997), skraćen za komentare i prikaz. C# je napisan u stilu biblioteke MiniNetLogo s kursa.

NetLogo
to go
  if all? turtles [ happy? ] [ stop ]
  ask turtles with [ not happy? ]
    [ find-new-spot ]       ; move-unhappy-turtles
  update-turtles
  update-globals
  tick
end

to find-new-spot
  rt random-float 360
  fd random-float 10
  if any? other turtles-here [ find-new-spot ]
  move-to patch-here        ; u sredinu parcele
end

to update-turtles
  ask turtles [
    set similar-nearby count (turtles-on neighbors)
      with [ color = [ color ] of myself ]
    set other-nearby count (turtles-on neighbors)
      with [ color != [ color ] of myself ]
    set total-nearby similar-nearby + other-nearby
    set happy? similar-nearby >=
      (%-similar-wanted * total-nearby / 100)
  ]
end
C#
static bool Go()
{
    if (World.Turtles.All(t => t.Happy)) return false;  // stop
    World.Ask(osobe.With(t => !t.Happy), t => t.FindNewSpot());
    UpdateTurtles();
    UpdateGlobals();
    World.Tick();
    return true;
}

public void FindNewSpot()                   // metoda klase Osoba
{
    this.Right(World.RandomFloat(360));
    this.Forward(World.RandomFloat(10));
    if (this.PatchHere.TurtlesHere.Other(this).Any())
        this.FindNewSpot();
    this.MoveTo(this.PatchHere);
}

static void UpdateTurtles() => World.Ask(osobe, t =>
{
    var oko = t.PatchHere.Neighbors.TurtlesOn<Osoba>();
    t.SimilarNearby = oko.Count(o => o.Color == t.Color);
    t.OtherNearby = oko.Count(o => o.Color != t.Color);
    t.TotalNearby = t.SimilarNearby + t.OtherNearby;
    t.Happy = t.SimilarNearby >=
        SimilarWanted * t.TotalNearby / 100.0;
});

Ko se seli, određuje se na početku ticka (with [ not happy? ] pravi skup odmah). Zadovoljstvo se računa ponovo tek kada se presele sve nezadovoljne turtles.

Mjerenje

Mijenja se traženi udio, mjeri se dobijeni udio

Parametar je %-similar-wanted: šta pojedinac traži. Mjera je percent-similar: šta grad na kraju ima. Razlika između ta dva broja je poenta modela.

% sličnih (percent-similar)

Od svih susjednih parova u gradu, koliko je iste boje. Na početku je grad izmiješan, pa je ta vrijednost blizu 50% (izmjereno: ).

% nezadovoljnih (percent-unhappy)

Koliko turtles se u tom ticku želi seliti. Nula znači da je model stao.

tickova do stabilizacije

Koliko je tickova prošlo dok sve turtles nisu bile zadovoljne. U mjerenju je granica tickova; ko je dostigne, nije se stabilizovao.

NetLogo (update-globals)
let similar-neighbors sum [ similar-nearby ] of turtles
let total-neighbors sum [ total-nearby ] of turtles
set percent-similar
  (similar-neighbors / total-neighbors) * 100
set percent-unhappy
  (count turtles with [ not happy? ]) / (count turtles) * 100

Rezultat · NetLogo

Traženo 30%, dobijeno 75% sličnih susjeda

Zašto kriva ide u stepenicama

Broj susjeda je cijeli broj. Uz osam susjeda prag od 25% traži 2 iste boje, a 30% traži 3 (2,4 se zaokružuje naviše); 75% traži 6, a 76% traži 7. Zato između 25% i 30%, i između 75% i 76%, ishod skače.

Tok · NetLogo

Do 75% grad se razdvaja; na 80% selidba ne prestaje i grad ostaje izmiješan

% sličnih i % nezadovoljnih kroz 300 tickova, 20 pokretanja po pragu. Linija je medijan, a pojas raspon među pokretanjima. Izaberite prag.

Zašto na 80% nema ni segregacije

Od 76% naviše turtle s osam susjeda traži bar sedam svoje boje. Takvih mjesta skoro da nema, pa se gotovo svi sele u svakom ticku, a stalna selidba održava grad izmiješanim.

Stabilizacija · NetLogo

Što je zahtjev veći, smirivanje traje duže; iznad 75% ne dolazi

Tumačenje

Ishod na nivou grada ne mora odgovarati namjeri pojedinaca

Schelling (1971): blaga individualna preferencija dovoljna je za jaku podjelu. Model to pokazuje bez ijednog podatka o stvarnom gradu.

Slike su iz prezentacije v02a (NetLogo, export-view, fiksni random-seed).

Mikro i makro se razlikuju

Turtle koja traži 30% prihvata da je 70% susjeda druge boje. Grad se ipak razdvoji, jer svaka selidba mijenja susjedstvo i drugima. Zato postojanje segregacije samo po sebi ne dokazuje nečiju namjeru.

Tri režima jednog parametra

  • malo traženo: grad ostaje blizu slučajnog rasporeda;
  • od oko 30% do 75%: jaka segregacija, sve sporije smirivanje;
  • iznad 75%: bez stabilizacije i bez segregacije.

Granice modela

Dvije grupe, isti prag za sve, besplatna selidba i nema cijena stanova. Model ne opisuje konkretan grad; tvrdi samo da je blaga sklonost dovoljna za oštru podjelu.

Šta isprobati

  • Postavite %-similar-wanted na 25, pa na 30. Prije pokretanja zapišite očekivani % sličnih. Zašto je skok tako velik?
  • Smanjite density na 70%. Mijenja li se granica iznad koje se grad ne smiri?
  • U find-new-spot zamijenite fd random-float 10 sa move-to one-of patches with [ not any? turtles-here ]. Mijenja li se ishod ili samo brzina?
