Model stava: širenje stava u društvu

Dvije vrste agenata, dva atributa i jedno pravilo razgovora. Bez medija stavovi se približavaju sredini, a s medijima se pomjeraju prema poruci medija.

Model s vježbi 2 korak po korak: agenti, atributi, interakcija, mediji, jedan tick, mjere i rezultat iz NetLoga. Isti kod prikazan je i u C#.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Agenti

Dvije vrste agenata: ljudi se kreću, mediji ne

U NetLogu je vrsta agenata breed. U C# je to klasa izvedena iz Turtle, a skup agenata je lista.

  • ljudi (200): kreću se svaki tick i mijenjaju stav u razgovoru.
  • mediji (4): nepokretni; predstavljaju ustanovu koja stalno šalje istu poruku.
  • Breed se deklariše na vrhu koda, prije svih procedura. Poslije toga se koristi ask ljudi, a ne ask turtles, jer bi se tada kretali i mediji.

U vašoj temi

Koje su vrste agenata? Vrsta je opravdana kada se agenti ponašaju različito (kreću se, mijenjaju se ili djeluju na druge), a ne samo kada imaju drugo ime.

NetLogo
breed [ ljudi covjek ]    ; pokretni agenti
breed [ mediji medij ]    ; nepokretni agenti

ask ljudi [ kreni ]       ; samo ljudi
C#
class Covjek : Turtle { }    // breed ljudi
class Medij : Turtle { }     // breed mediji

List<Covjek> ljudi = new();
List<Medij> mediji = new();
foreach (var c in ljudi.Shuffle()) c.Kreni();
Atributi

Dva atributa: stav i integritet

Svaki čovjek ima stav od −1 (protiv) do +1 (za) i integritet od 0 (lako mijenja stav) do 1 (ne mijenja ga). Obje vrijednosti su na početku slučajne, uniformno raspoređene.

oboji: stav > 0,2 plavo · stav < −0,2 crveno · inače sivo
  • Uniformna raspodjela (random-float) daje na početku oko 40% „za“, 40% „protiv“ i 20% neodlučnih. U 20 pokretanja u NetLogu izmjereno je prosječno „za“ i „protiv“.
  • Raspodjela se bira prema izvoru: ako istraživanje kaže da je većina neodlučna, prikladnija je npr. random-normal 0 0.4, uz ograničenje na −1..1.
NetLogo
ljudi-own [
  stav          ; -1 (protiv) do +1 (za)
  integritet    ; 0 (lako se mijenja) do 1
]
; u setup, za svakog čovjeka:
set stav (random-float 2) - 1
set integritet random-float 1
C#
class Covjek : Turtle
{
    public double Stav;         // -1 .. +1
    public double Integritet;   // 0 .. 1
}
// u Setup():
c.Stav = rng.NextDouble() * 2 - 1;
c.Integritet = rng.NextDouble();
Interakcija

Jedan razgovor: stav se pomjeri prema sagovorniku

Čovjek izabere slučajnog sagovornika u dometu i pomjeri svoj stav prema njegovom. Koliko, zavisi od razlike, od njegovog integriteta i od parametra uticaj. Pomjerite klizače.

NetLogo
to razgovaraj
  let sagovornik one-of other ljudi in-radius domet
  if sagovornik != nobody [
    let razlika ([ stav ] of sagovornik) - stav
    set stav stav + razlika * (1 - integritet) * uticaj
  ]
end
C#
void Razgovaraj()             // metoda klase Covjek
{
    var sagovornik = ljudi
        .Where(o => o != this && Dist(o, this) <= domet)
        .Shuffle().FirstOrDefault();
    if (sagovornik == null) return;   // nobody
    var razlika = sagovornik.Stav - Stav;
    Stav += razlika * (1 - Integritet) * uticaj;
}
Scenarij

Mediji: isto pravilo, ali poruka je uvijek ista

Čovjek u dometu medija pomjeri stav prema poruci medija. Prekidač mediji-rade? određuje scenarij; kod je u oba scenarija isti.

poruka-medija = 1

Stav kojem mediji vuku. Vrijednost −1 bila bi kampanja „protiv“, a 0 kampanja za umjerenost.

snaga-medija = 0,1

Dio razlike do poruke koji se pređe u jednoj sedmici; slabije od razgovora (uticaj = 0,2), ali djeluje svaki tick.

domet-medija = 8

Medij djeluje na ljude u krugu poluprečnika 8 parcela. Ljudi daleko od svih medija čuju samo razgovore.

Zašto mediji pomjeraju prosjek, a razgovor ne?

U razgovoru se jedan stav pomjera prema drugom stavu iz iste populacije. Poruka medija je izvan populacije i uvijek ista, pa djeluje stalno u istom smjeru.

NetLogo
to slusaj-medije
  if any? mediji in-radius domet-medija [
    set stav stav + (poruka-medija - stav)
                    * (1 - integritet) * snaga-medija
  ]
end
; u go: if mediji-rade? [ slusaj-medije ]
C#
void SlusajMedije()
{
    if (mediji.Any(m => Dist(m, this) <= dometMedija))
        Stav += (porukaMedija - Stav)
                * (1 - Integritet) * snagaMedija;
}
// u Go(): if (medijiRade) c.SlusajMedije();
Vrijeme

Jedan tick je jedna sedmica: svaki čovjek prođe četiri koraka

Boja prati novi stav, pa se promjena vidi u prikazu svijeta.

NetLogo
to go
  ask ljudi [
    kreni
    razgovaraj
    if mediji-rade? [ slusaj-medije ]
    oboji
  ]
  update-mjere
  tick
end
C#
void Go()
{
    foreach (var c in ljudi.Shuffle())    // ask ljudi
    {
        c.Kreni(); c.Razgovaraj();
        if (medijiRade) c.SlusajMedije();
        c.Oboji();
    }
    UpdateMjere();
    ticks++;                              // tick
}
Mjere

Mjere su globalne promjenljive koje se računaju svaki tick

Rad se piše na osnovu brojeva, a ne na osnovu slike svijeta. Iste mjere čita BehaviorSpace kada pokreće model više puta.

  • prosječan stav: kuda se društvo u cjelini pomjera;
  • udio „za“ (stav > 0,2): koliko je ljudi izrazito za;
  • udio „protiv“ (stav < −0,2) i standardna devijacija stava: izmjereni su dodatno, u eksperimentu, bez izmjene modela.

Zašto više mjera

Bez medija prosjek ostaje gotovo isti, a udjeli „za“ i „protiv“ padaju. Ko gleda samo prosjek, zaključiće da se ništa nije desilo (slajd 9).

NetLogo
globals [ prosjecan-stav  udio-za ]

to update-mjere
  set prosjecan-stav mean [ stav ] of ljudi
  set udio-za (count ljudi with [ stav > 0.2 ])
              / (count ljudi)
end
C#
double prosjecanStav, udioZa;    // globals

void UpdateMjere()
{
    prosjecanStav = ljudi.Average(c => c.Stav);
    udioZa = ljudi.Count(c => c.Stav > 0.2)
             / (double)ljudi.Count;
}

Mjere · NetLogo

Prosjek ostaje gotovo isti, a raspodjela se mijenja

Raspodjela stavova 200 ljudi u jednom pokretanju (NetLogo, random-seed 1). Isprekidana linija je prosjek.

Razgovor približava stavove jedne drugima: bez medija gotovo svi završe neodlučni, a prosjek je i dalje blizu nule. Mediji pomjere prosjek, ali ne podjednako: ljudi daleko od medija ostaju sivi.
