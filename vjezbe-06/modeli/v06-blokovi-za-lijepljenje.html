V06 · Kod za copy-paste

U vlastitoj kopiji v06-alat-pocetak.nlogox zamijenite cijelo tijelo navedene procedure između postojećih redova to naziv i end. Kopirajte samo sadržaj okvira. Pratite korake A–E. Za dostizanje koraka k u početnoj datoteci primijenite sve blokove A..k. Nakon svakog koraka odaberite Check, pokrenite setup i izvršite provjeru.

U koracima A i B odgođeni su redovi koraka C. C sadrži cijela završena tijela procedura za centar i domaćinstva. D dodaje poznanstva. E prikazuje postojeće tijelo procedure setup radi poređenja. Deklaracije i reportere zadržite. Osnovne postavke su sjeme 1, zaliha 10 i granice početnog stava 0 i 1.

Korak A

postavi-svijet

Zamijenite tijelo između to postavi-svijet i end.

  ;; korak A — prostor bez spajanja rubova.
  resize-world -10 10 -10 10
  set-topology false false
  ask patches [set pcolor 9]

postavi-centar

Zamijenite tijelo između to postavi-centar i end.

  ;; korak A — centar na sredini naselja.
  set centar patch 0 0
  ask centar [
    set pcolor orange
  ]

Korak B

postavi-domacinstva

Zamijenite tijelo između to postavi-domacinstva i end.

  ;; korak B — različiti patchevi, tačno u njihovim središtima.
  ask n-of 100 patches with [self != centar] [
    sprout-domacinstva 1 [
      set shape "house"
      set size 0.8
      set color sky
    ]
  ]

Korak C

postavi-centar

Zamijenite tijelo između to postavi-centar i end.

  ;; korak A — centar na sredini naselja.
  set centar patch 0 0
  ask centar [
    set pcolor orange
    ;; korak C — početno su svi komadi raspoloživi.
    set raspolozivo zaliha
  ]

postavi-domacinstva

Zamijenite tijelo između to postavi-domacinstva i end.

  ;; korak B — različiti patchevi, tačno u njihovim središtima.
  ask n-of 100 patches with [self != centar] [
    sprout-domacinstva 1 [
      set shape "house"
      set size 0.8
      set color sky
      ;; korak C — početni atributi domaćinstva.
      set stav pocetni-stav-min + random-float (pocetni-stav-max - pocetni-stav-min)
      set integritet random-float 1
      set budzet random-float 8
      set posudba 0
      set iskustvo "nema"
      set posudio-ikad? false
    ]
  ]

Kontrolna tačka (60 s) · U chat upišite C | radi ili C | poruka greške. Ako ste završili ranije, osmislite dodatnu provjeru.

Korak D

postavi-poznanstva

Zamijenite tijelo između to postavi-poznanstva i end.

  ;; korak D — jedan pokušaj po dopuštenom neuređenom paru.
  ask domacinstva [
    let kandidati (other domacinstva in-radius 4) with [who > [who] of myself]
    ask kandidati [
      if random-float 1 < 0.3 [
        create-poznanstvo-with myself [
          set color gray
          set thickness 0.08
        ]
      ]
    ]
  ]

Kontrolna tačka (60 s) · U chat upišite D | radi ili D | poruka greške. Ako ste završili ranije, osmislite dodatnu provjeru.

Korak E

setup

Zamijenite tijelo između to setup i end.

  clear-all
  random-seed sjeme
  if pocetni-stav-min > pocetni-stav-max [
    error "Početni minimum stava treba biti manji ili jednak maksimumu."
  ]
  postavi-svijet
  postavi-centar
  postavi-domacinstva
  postavi-poznanstva
  ;; korak E — ponoviti setup i uporediti sortirane zapise.
  reset-ticks

Kontrolna tačka (60 s) · U chat upišite E | radi ili E | poruka greške. Ako ste završili ranije, osmislite dodatnu provjeru.
