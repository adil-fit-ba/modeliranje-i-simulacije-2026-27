C · početne raspodjele su pretpostavke

A4 §4„Početno ravnomjerna raspodjela 0–1 [P].“
C# · analogija
d.Stav = min + rng.NextDouble()
    * (max - min);
d.Integritet = rng.NextDouble();
d.Budzet = rng.NextDouble() * 8;

NextDouble() je analogija za random-float 1. Za ovu osnovnu verziju granice stava su 0 i 1.

NetLogo · isječak iz v06-alat-svijet.nlogox
      set stav pocetni-stav-min + random-float (pocetni-stav-max - pocetni-stav-min)
      set integritet random-float 1
      set budzet random-float 8

Zašto ovako

random-float daje realne vrijednosti. Ravnomjernost dolazi iz A4, a nije zaključak iz podataka. Kasnije ispitujemo osjetljivost na početni stav.

Zašto ne random 1?

Cjelobrojni rezultat bio bi uvijek 0. random 8 daje cijele iznose, a ne traženu kontinuiranu raspodjelu budžeta.

Provjera · Command Center, posmatrač

show count domacinstva with [stav < 0 or stav > 1 or integritet < 0 or integritet > 1 or budzet < 0 or budzet > 8]

0 vrijednosti izvan raspona. Gornja granica izvlačenja je isključena: stav i integritet su manji od 1, budžet je manji od 8. Sama provjera raspona ne dokazuje ravnomjernost.

D · jednom po paru, zatim jedno izvlačenje

A4 §3„Svaki par domaćinstava udaljenih najviše 4 patcha povezan je s vjerovatnoćom 0,3 [P]. Veze su uzajamne i stalne.“
C# · analogija
foreach (var a in domacinstva)
 foreach (var b in domacinstva.Where(
  b => b.Who > a.Who &&
       b.Distance(a) <= 4))
  if (rng.NextDouble() < 0.3)
   PoveziUzajamno(a, b);

C# imena a i b razjašnjavaju kontekst. NetLogo dodatno miješa redoslijed svakog ask.

NetLogo · isječak iz v06-alat-svijet.nlogox
to postavi-poznanstva
  ;; korak D — jedan pokušaj po dopuštenom neuređenom paru.
  ask domacinstva [
    let kandidati (other domacinstva in-radius 4) with [who > [who] of myself]
    ask kandidati [
      if random-float 1 < 0.3 [
        create-poznanstvo-with myself [
          set color gray
          set thickness 0.08
        ]
      ]
    ]
  ]
end

Zašto ovako

who > [who] of myself uzima samo drugi kraj s većim ID-em. U with je self kandidat, myself vanjsko domaćinstvo. U unutrašnjem ask veza nastaje prema vanjskom domaćinstvu.

Zašto ne izostaviti uslov s who?

Svaki par dobija dva pokušaja. Vjerovatnoća barem jednog uspjeha je 1 − 0,7² = 0,51 (račun iz pravila). Ne nastaju duple neusmjerene veze, ali mreža postaje gušća. undirected-link-breed [poznanstva poznanstvo] izražava uzajamnost.

Provjera · Command Center, posmatrač

show count poznanstva with [link-length > 4]

0 predugih veza. Ovaj upit prolazi i bez uslova s who, zato treba provjeriti i kod izbora parova.
