Mreža poznanstava

Uticaj se prenosi preko poznanika, a ne preko slučajnih prolaznika.

Model stava isti je kao na vježbama 2, ali ljudi su nepokretni i razgovaraju s poznanicima. Izbor veza dio je oblikovanja modela i određuje doseg širenja poruke.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Pojava

Na stav utiču poznanici, a ne slučajni prolaznici

Na vježbama 2 sagovornik je biran među ljudima u dometu. Ovdje je sagovornik poznanik: susjed, kolega ili rođak. Neki poznanici žive daleko.

Prolaznici (vježbe 2)

Ljudi se kreću; sagovornik može biti bilo ko u dometu. S vremenom čovjek sretne mnogo različitih ljudi.

Poznanici

Ljudi su nepokretni; svako se poveže sa 3 najbliža čovjeka, a dio veza zatim se preusmjeri na udaljene ljude. Razgovara se isključivo s poznanicima.

Daleka veza

Poznanik na drugom kraju grada. Takva veza omogućava neposredan prijenos poruke preko velike prostorne udaljenosti.

Gdje se to javlja

Prenošenje stava među članovima porodice, susjedima i kolegama umjesto slučajnim susretima; razlika između zatvorene sredine i sredine s brojnim vanjskim vezama.

Sastavni dijelovi

Ljudi na stalnim mjestima, veze kao agenti, mediji i dva nova parametra

Stav, integritet i mediji su isti kao u modelu stava s vježbi 2. Nove su veze.

Ljudi · nepokretni

  • mjesto je stalno: kuća, posao
  • stav i integritet kao u modelu stava
ljudi-own [ stav integritet ] · bez procedure kreni

Veze · links

  • veza je agent: ima krajnje tačke i boju te se može ukloniti (die)
  • broj-veza = 3: svako se poveže sa svoja 3 najbliža
  • prosječno oko 3,7 poznanika po osobi: uz vlastita 3 izbora čovjek uspostavlja veze i s onima koji su izabrali njega, dok obostrani izbor stvara samo jednu vezu

Daleke veze

  • udio-dalekih-veza: udio veza koje se preusmjere na ljude bilo gdje u prostoru modela (0 do 1)

Mediji · dvije kuće

  • poruka +1, domet-medija = 5
  • čuju ih samo oni koji žive blizu kuće
  • mjera: udio-za (stav > 0,2)
Interakcija

Formiranje mreže i izbor sagovornika

Prva dva koraka izvršavaju se jednom, u setup. Preostala dva izvršavaju se svake sedmice, u go.

1 Tri najbliža

Svako stvori veze sa svoja 3 najbliža čovjeka.

create-links-with min-n-of broj-veza other ljudi [ distance myself ]

2 Preusmjeravanje dijela veza

S vjerovatnoćom jednakom udio-dalekih-veza, postojeća veza zamijeni se novom vezom s osobom bilo gdje u prostoru modela.

let a end1 · ask a [ create-link-with novi ] · die

3 Razgovor s poznanikom

Sagovornik je jedan slučajno izabran poznanik, nezavisno od mjesta stanovanja.

let sagovornik one-of link-neighbors

4 Mediji samo u blizini

Poruku čuju samo ljudi koji žive u dometu kuće medija. Do ostalih može stići preko poznanika.

if any? mediji in-radius domet-medija [ … ]
Probajte

Daleke veze skraćuju put između ljudi

Mala mreža za ilustraciju: 30 ljudi u krugu, svako povezan s po dva susjeda sa svake strane. Kliknite na čovjeka: boja pokazuje broj koraka (razgovora) potrebnih da njegova poruka stigne do svakog drugog čovjeka.

Ovo nije mreža iz modela, nego pojednostavljen primjer: ljudi su raspoređeni u krug radi jasnijeg prikaza dužine puta. Isti princip opisali su Watts i Strogatz (1998): i mali udio dalekih veza znatno skraćuje put između ljudi.

Kod

Izbor sagovornika: one-of link-neighbors

Lijevo je prikazan NetLogo kod, a desno odgovarajući C# kod (projekat netlogo-kroz-csharp).

NetLogo · v03-blok3-mreza.nlogox
to napravi-mrezu
  ask ljudi [
    ① create-links-with
      min-n-of broj-veza other ljudi [ distance myself ]
  ]
  ② ask links [
    if random-float 1 < udio-dalekih-veza [
      let a end1
      let novi one-of ljudi with
        [ self != a and not link-neighbor? a ]
      if novi != nobody [
        ask a [ create-link-with novi ]
        die
      ]
    ]
  ]
end

to razgovaraj
  ③ let sagovornik one-of link-neighbors
  if sagovornik != nobody [
    let razlika ([ stav ] of sagovornik) - stav
    set stav stav + razlika * (1 - integritet) * uticaj
  ]
end
C# · Blokovi/Blok3Mreza.cs
static void NapraviMrezu()            // observer: nema this
{
    World.Ask(ljudi, c =>
        ① c.CreateLinksWith(ljudi.Other(c)
            .MinNOf(Globals.BrojVeza, d => d.Distance(c))));
    ② World.Ask(World.Links, l =>
    {
        if (World.RandomFloat(1) < Globals.UdioDalekihVeza)
        {
            var a = l.End1;
            var novi = ljudi.With(d => !ReferenceEquals(d, a)
                                    && !d.IsLinkNeighbor(a)).OneOf();
            if (novi != null)
            {
                World.Ask(new[] { a }, x => x.CreateLinkWith(novi));
                l.Die();
            }
        }
    });
}

public void Razgovaraj()              // metoda klase Covjek
{
    ③ var sagovornik = this.LinkNeighbors.OfType<Covjek>().OneOf();
    if (sagovornik != null)
    {
        double razlika = sagovornik.Stav - this.Stav;
        this.Stav += razlika * (1 - this.Integritet) * Globals.Uticaj;
    }
}
①U [ distance myself ] izraz računa svaki kandidat, a myself je čovjek koji traži poznanike. U C#: kandidat je d, a myself je c iz vanjske lambde.
②Veze su agenti, pa i njima ide ask. Nova veza napravljena tokom ask links nije na redu: ask prolazi kroz kopiju skupa.
③Jedini red koji se razlikuje od modela stava. Umjesto one-of other ljudi in-radius domet sagovornik je poznanik.
Ishod

Daleke veze proširuju doseg poruke medija

Dva pokretanja modela u NetLogu uz isti seed: isti ljudi, iste kuće i iste početne veze. Razlikuju se samo po preusmjeravanju dijela veza pri udjelu dalekih veza od 20%.

U oba pokretanja ljudi u blizini kuća brzo usvajaju stav „za“. Bez dalekih veza poruka se širi samo među susjedima i ne doseže dijelove mreže nepovezane s kućama. Daleke veze omogućavaju prijenos poruke i u te dijelove.

Ishod

Više dalekih veza povećava udio „za“, uz veliko rasipanje

Rasipanje je veliko, jer ishod zavisi i od toga gdje su kuće medija i kako su povezani ljudi oko njih.

Primjena u vlastitom modelu

Odredite razgovaraju li ljudi u vašem modelu s prolaznicima (kretanje, kao na vježbama 2) ili s poznanicima (veze). Za opis veza potrebni su podaci o broju poznanika po osobi i broju poznanika izvan njene okoline.

Zadaci za provjeru

  • Postavite udio dalekih veza redom na 0, 0,2 i 1; svaki put izvršite repeat 500 [ go ] i uporedite udio „za“.
  • Isključite prikazi-veze? i na osnovu boja utvrdite gdje se stav „za“ najprije pojavljuje.
  • U Command Centeru izvršite show mean [ count link-neighbors ] of ljudi i očitajte prosječan broj poznanika po osobi.
