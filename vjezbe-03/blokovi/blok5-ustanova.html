Iskustvo s ustanovom

Neposredno iskustvo s ustanovom stiče se posjetom. Razgovor prenosi informacije o tom iskustvu.

Ustanova ima stalno mjesto: u NetLogu je predstavlja patch s vlastitom varijablom. Čovjek koji stane na taj patch doživi dobro ili loše iskustvo, a ostali o tom iskustvu saznaju samo u razgovoru.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Pojava

Vlastito i tuđe iskustvo oblikuju povjerenje u ustanovu

Osoba koja je bila na šalteru ima vlastito iskustvo. Osoba koja nije bila o njemu saznaje samo od drugih.

Posjetioci: neposredno iskustvo

Svaka posjeta donosi dobro ili loše iskustvo. Povjerenje se mijenja prema 1 ili prema 0.

Neposjetioci: bez neposrednog iskustva

Na početku niko nema iskustva, pa svi imaju isto povjerenje, 0,5.

Razgovor: tuđe iskustvo

Kao u modelu stava s vježbi 2: povjerenje čovjeka koji započne razgovor približi se povjerenju sagovornika.

Gdje se to javlja

Povjerenje u ustanove kao što su šalter općine, ambulanta ili studentska služba; mišljenje o bilo kojoj javnoj usluzi koju ljudi koriste povremeno, a o kojoj stalno slušaju od drugih.

Sastavni dijelovi

Ljudi koji se kreću i ustanove na stalnim mjestima

U odnosu na model stava, ustanova se predstavlja patchem s vlastitom varijablom umjesto agentom tipa turtle.

Ljudi · kreću se

  • povjerenje od 0 do 1; na početku svi 0,5
  • integritet od 0 (mijenja se najlakše) do 1 (ne mijenja se)
  • posjeta: koliko puta je bio u ustanovi
ljudi-own [ povjerenje integritet posjeta ]
C#: class Covjek : Turtle

Ustanove · patchevi

  • patch ima varijablu ustanova?
  • broj-ustanova patcheva (zadano 20) dobije true i narandžastu boju
  • nepokretne: patch se ne može pomjeriti
patches-own [ ustanova? ]
C#: class UstanovaPatch : Patch

Parametri · klizači

  • udio-losih-iskustava: vjerovatnoća lošeg iskustva pri dolasku (zadano 0,7)
  • snaga-iskustva = 0,6: koliki dio razlike do 0 ili 1 obuhvata promjena nakon iskustva
  • razgovor?, domet = 3, uticaj = 0,2, kao u modelu stava

Mjere · izlaz modela

  • prosjecno-povjerenje svih ljudi
  • udio-posjetilaca: udio ljudi koji su barem jednom bili u ustanovi
  • povjerenje onih koji su bili i onih koji nisu (dva reportera)
Interakcija

Kretanje, provjera mjesta, iskustvo i razgovor

Svake sedmice svaki čovjek, slučajnim redom (ask ljudi), prođe ova četiri koraka.

1 Kretanje

Okrene se slučajno i napravi jedan korak.

right random 360 · forward 1

2 Provjera patcha na kojem čovjek stoji

Provjeri predstavlja li patch na kojem stoji ustanovu.

if [ ustanova? ] of patch-here [ iskustvo ]

3 Iskustvo

Iskustvo je loše s vjerovatnoćom jednakom udio-losih-iskustava; inače je dobro. Promjena povjerenja je (cilj − povjerenje) × (1 − integritet) × snaga.

ifelse random-float 1 < udio-losih-iskustava [ … ] [ … ]

4 Razgovor

Ako je razgovor? uključen, razgovara s jednim čovjekom u dometu, kao u modelu stava.

if razgovor? [ razgovaraj ]
Probajte

Numerički primjer iskustva

Postavite povjerenje i integritet, zatim izaberite iskustvo. Prikaz odgovara postupku procedure iskustvo kada čovjek stane na patch koji predstavlja ustanovu.

Izaberite nekoliko loših iskustava zaredom. Svako sljedeće uzrokuje manju promjenu povjerenja jer se razlika do 0 smanjuje. Zatim postavite integritet na 0,9: ista iskustva uzrokuju vrlo male promjene.

Kod

Patch s vlastitom varijablom i provjera mjesta

Lijevo NetLogo, desno isti kod u C# (projekat netlogo-kroz-csharp, Blokovi/Blok5Ustanova.cs).

NetLogo · v03-blok5-ustanova.nlogox
① patches-own [ ustanova? ]
ljudi-own [ povjerenje integritet posjeta ]

;; u setup
ask patches [ set ustanova? false ]
ask n-of broj-ustanova patches [
  set ustanova? true
  set pcolor orange
]

;; u go, za svakog čovjeka
② if [ ustanova? ] of patch-here [ iskustvo ]

to iskustvo
  set posjeta posjeta + 1
  ③ ifelse random-float 1 < udio-losih-iskustava
    [ set povjerenje povjerenje +
        (0 - povjerenje) * (1 - integritet) * snaga-iskustva ]
    [ set povjerenje povjerenje +
        (1 - povjerenje) * (1 - integritet) * snaga-iskustva ]
end
C# · Blokovi/Blok5Ustanova.cs
① public class UstanovaPatch : Patch
{
    public bool Ustanova;           // ustanova?
}

// patch-here vraća Patch; naši su UstanovaPatch
public UstanovaPatch MjestoIspod => (UstanovaPatch)this.PatchHere;

// u Go, za svakog čovjeka c
② if (c.MjestoIspod.Ustanova) c.Iskustvo();

public void Iskustvo()
{
    this.Posjeta += 1;
    ③ if (World.RandomFloat(1) < Globals.UdioLosihIskustava)
        this.Povjerenje += (0 - this.Povjerenje)
            * (1 - this.Integritet) * Globals.SnagaIskustva;
    else
        this.Povjerenje += (1 - this.Povjerenje)
            * (1 - this.Integritet) * Globals.SnagaIskustva;
}
①patches-own daje svakom patchu novu varijablu. U C# je to podklasa klase Patch, kao GrassPatch u modelu Wolf Sheep.
②patch-here je patch na kojem čovjek stoji. U C# vraća opšti Patch, pa se pretvara u UstanovaPatch da bi se vidjela varijabla.
③Slučajnost: random-float 1 daje broj od 0 do 1; manji od udjela loših znači loše iskustvo. Svugdje je napisano this., pa se vidi čiji se atribut mijenja.
Ishod

Bez razgovora mijenja se samo povjerenje posjetilaca

Svaka linija prikazuje povjerenje jednog čovjeka tokom 150 sedmica. Prikazano je pokretanje modela u NetLogu uz 70% loših iskustava.

Bez razgovora povjerenje neposjetilaca ostaje na 0,5, dok se povjerenje posjetilaca mijenja skokovito, najčešće naniže; svaki skok odgovara jednoj posjeti.

Uz razgovor se povjerenje posjetilaca djelimično približava povjerenju ostalih, dok se povjerenje ostalih približava povjerenju posjetilaca, iako nikad nisu bili u ustanovi.

Primjena u vlastitom modelu

Model na papiru

Zapis bloka u modelu na papiru

Model se prvo opisuje na papiru, a zatim u kodu. Blok uvodi jednog nepokretnog aktera i dvije interakcije.

Podaci za koje treba navesti izvor

Udio loših iskustava (npr. anketa o zadovoljstvu korisnika), snaga iskustva i učestalost posjeta ustanovi. U modelu tu učestalost određuje broj-ustanova.

Zadaci za provjeru

  • Postavite broj-ustanova na 5, zatim na 40. Izmjereno (70% loših iskustava, s razgovorom): ustanovu posjeti …, odnosno … ljudi; prosječno povjerenje je …, odnosno ….
  • Postavite udio-losih-iskustava na 0,5 i objasnite zašto se prosjek ne mijenja, dok se povjerenje pojedinaca mijenja.
  • U Command Centeru izvršite ask patches with [ ustanova? ] [ set pcolor green ]: patch je agent kao i turtle.
