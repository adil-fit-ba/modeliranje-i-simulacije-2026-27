Preseljenje

Čovjek se preseljava ako je udio sličnih susjeda manji od traženog.

Niko u modelu ne traži da većina susjeda pripada njegovoj grupi. Dovoljno je da svako želi barem 30% sličnih susjeda: nakon nekoliko mjeseci istoj grupi pripada prosječno oko tri četvrtine susjeda.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Pojava

Blaga sklonost sličnim susjedima može dovesti do izražene podjele

Zahtjev je nizak: čovjek ostaje ako je barem 30% njegovih susjeda iz iste grupe. Uprkos tome, u cijelom prostoru modela nastaje izražena podjela.

3 od 8 sličnih: ostaje

Traži se barem 30%: 3 ≥ 0,3 × 8 = 2,4. Čovjek je zadovoljan, iako je u manjini.

2 od 8 sličnih: seli se

2 je manje od 2,4. Čovjek se preseli na slučajno odabrano prazno mjesto bilo gdje u prostoru modela.

Posljedica: prostorna podjela grupa

Kada su svi zadovoljni, većina susjeda pripada istoj grupi, iako takav zahtjev nije postavljen.

Gdje se to javlja

Susjedstva podijeljena po bilo kojoj osobini; sjedenje po grupama u amfiteatru ili menzi. Grupa u modelu je bilo koja osobina po kojoj ljudi razlikuju „slične“ od „drugih“.

Sastavni dijelovi

Ljudi na mjestima, jedna osobina, dva parametra i dvije mjere

U ovom bloku ljudi se ne kreću nasumično, nego borave na patchevima i preseljavaju se s jednog na drugi.

Ljudi · borave na mjestima

  • grupa: 0 ili 1, nasumično na početku
  • susjeda, slicnih: koliko ljudi je na 8 okolnih mjesta i koliko ih je iz iste grupe
  • zadovoljan?: računa se iz ta dva broja
breed [ ljudi covjek ] · ljudi-own [ grupa slicnih susjeda zadovoljan? ]
C#: class Covjek : Turtle { int Grupa, Slicnih, Susjeda; bool Zadovoljan; }

Mjesta · patchevi

  • 41 × 41 = 1681 mjesto, na svakom najviše jedan čovjek
  • uz gustinu 70% živi 1177 ljudi, a 504 mjesta su prazna
  • prostor modela je torus: susjedi se određuju i preko ruba
ask n-of (round (gustina * count patches)) patches [ sprout-ljudi 1 [ … ] ]

Parametri · klizači

  • trazeni-udio-slicnih = 0,3: najmanji udio sličnih među susjedima uz koji čovjek ostaje
  • gustina = 0,7: udio zauzetih mjesta

Mjere · izlaz modela

  • prosjecno-slicnih: prosječan udio sličnih među susjedima (za ljude koji imaju barem jednog susjeda)
  • udio-nezadovoljnih; model se zaustavlja kada je vrijednost 0
Interakcija

Tok jednog mjeseca

Interakcija ovdje nije razgovor: čovjek procjenjuje sastav susjedstva i na osnovu toga odlučuje o ostanku.

1 Prebrojavanje susjeda

Na 8 okolnih mjesta nalazi se 6 ljudi, od kojih 2 pripadaju grupi posmatranog čovjeka.

let oko-mene ljudi-on neighbors

2 Procjena zadovoljstva

Broj sličnih susjeda poredi se s brojem koji odgovara traženom udjelu svih susjeda. Čovjek bez susjeda smatra se zadovoljnim (0 ≥ 0).

set zadovoljan? slicnih >= trazeni-udio-slicnih * susjeda

3 Nezadovoljni se presele

Skup nezadovoljnih agenata određuje se prije prvog preseljenja (with). Zatim se agenti slučajnim redoslijedom preseljavaju na slučajno odabrana prazna mjesta.

ask ljudi with [ not zadovoljan? ] [ preseli-se ]

4 Ponovna procjena zadovoljstva

Selidba mijenja susjedstvo i ljudima koji ostaju. Zato se poslije selidbi ponovo procijeni zadovoljstvo svih ljudi. Kada nema nezadovoljnih, model se zaustavi.

procijeni · update-mjere · tick
Probajte

Numerički primjer susjedstva

Klik na susjedno mjesto mijenja njegovo stanje redom: prazno mjesto → plava grupa → narandžasta grupa. Klik na sredinu mijenja grupu čovjeka koji odlučuje. Isto radi procedura procijeni za jednog čovjeka.

Promijenite jednog plavog susjeda u narandžastog. Zatim postavite traženi udio na 0,5 i utvrdite potreban broj sličnih susjeda. Udio se računa od zauzetih mjesta, pa prazno mjesto mijenja i broj susjeda.

Kod

Tri mjesta u kodu koja treba razumjeti

Lijevo je prikazan NetLogo kod, a desno odgovarajući C# kod (projekat netlogo-kroz-csharp).

NetLogo · v03-blok4-preseljenje.nlogox
to go
  if not any? ljudi with [ not zadovoljan? ] [ stop ]
  ① ask ljudi with [ not zadovoljan? ] [ preseli-se ]
  procijeni
  update-mjere
  tick
end

to procijeni
  ask ljudi [
    let oko-mene ljudi-on neighbors
    set susjeda count oko-mene
    ② set slicnih count oko-mene
      with [ grupa = [ grupa ] of myself ]
    set zadovoljan?
      slicnih >= trazeni-udio-slicnih * susjeda
  ]
end

to preseli-se
  ③ move-to one-of patches with [ not any? ljudi-here ]
end
C# · Blokovi/Blok4Preseljenje.cs
public static bool Go()                     // to go
{
    if (!ljudi.With(c => !c.Zadovoljan).Any()) return false;
    ① World.Ask(ljudi.With(c => !c.Zadovoljan), c => c.PreseliSe());
    Procijeni();
    UpdateMjere();
    World.Tick();
    return true;
}

static void Procijeni()                     // to procijeni
{
    World.Ask(ljudi, c =>                   // c = onaj ko gleda (myself)
    {
        var okoMene = c.PatchHere.Neighbors.TurtlesOn<Covjek>();
        c.Susjeda = okoMene.Count;
        ② c.Slicnih = okoMene.Count(d => d.Grupa == c.Grupa);
        c.Zadovoljan =
            c.Slicnih >= Globals.TrazeniUdioSlicnih * c.Susjeda;
    });
}

// metoda klase Covjek: this = čovjek koji se seli
public void PreseliSe() =>                  // to preseli-se
    ③ this.MoveTo(World.Patches
        .With(p => !p.Here<Covjek>().Any()).OneOf()!);
①with prvo izdvoji sve nezadovoljne, a zatim ask svakom od njih izvrši preseljenje. Ko postane nezadovoljan zbog tuđe selidbe u istom mjesecu, čeka sljedeći mjesec. U C#: With(…) napravi spisak.
②Unutar with [ … ] riječ grupa je grupa susjeda koji se provjerava, a [ grupa ] of myself grupa čovjeka koji gleda oko sebe. U C#: d.Grupa == c.Grupa.
③Prazno mjesto se bira slučajno iz cijelog svijeta, a ne u blizini. Mjesto koje je čovjek upravo napustio postaje prazno za one koji se sele poslije njega.

Ishod

Stroži zahtjev odgađa ili onemogućava zadovoljstvo svih

Uz traženih 75% sličnih podjela je gotovo potpuna. Uz traženih 80% ljudi se sele i nakon 300 mjeseci, a podjele nema.

traženomjeseci do zadovoljstva svihsličnih na krajunezadovoljnih na kraju

Izostanak podjele uz zahtjev od 80%

Moguće objašnjenje (nije posebno mjereno): na slučajno odabranom praznom mjestu rijetko ima dovoljno sličnih susjeda, pa se većina preseljava svakog mjeseca, čime se održava izmiješanost grupa. Ishod zavisi od parametra na način koji se ne vidi iz samog pravila.

Model na papiru

Zapis bloka u modelu na papiru

Model se prvo opisuje na papiru, a zatim u kodu. Blok se zapisuje jednom rečenicom u polju „Interakcije“, uz potrebne atribute i parametre.

Podaci za koje treba navesti izvor

Traženi udio sličnih: koliki udio sličnih susjeda čovjek želi (npr. anketa). Gustina: udio zauzetih mjesta, iz kojeg slijedi broj praznih. Ako se zahtjevi ljudi razlikuju, bilježe se kao atribut, a ne jednim klizačem.

Primjena u vlastitom modelu

Objasnite nastanak podijeljenih susjedstava kada niko ne zahtijeva većinu susjeda iz vlastite grupe. Odredite mjeru koja bi pokazala takav ishod u vašem modelu.

Zadaci za provjeru

  • Prije pokretanja procijenite završni udio sličnih susjeda uz traženih 30%, zatim pokrenite go;
  • Postavite traženi udio na 0,8 i očitajte monitor nezadovoljnih nakon 100 mjeseci.
  • Postavite gustinu na 0,95 (malo praznih mjesta) i utvrdite mijenja li se ishod ili samo brzina promjene.
  • uporedite s modelom Social Science → Segregation iz Models Library.
