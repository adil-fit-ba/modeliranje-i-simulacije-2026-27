Prag i kaskada

Čovjek ustaje kada udio susjeda koji stoje dostigne njegov prag.

Uz isti prosječni prag može nastati talas koji zahvati cijelu salu ili gotovo izostati. Ishod zavisi od razlika među ljudima i od slučajnosti.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Pojava

Različiti pragovi određuju uslov ustajanja

Svako ima vlastiti prag: udio ljudi u okolini čije je učešće potrebno da bi se čovjek pridružio.

Pokretač: prag 0

Pokretač ustaje nezavisno od drugih. U modelu je nekoliko pokretača na slučajno odabranim mjestima.

Nizak prag

Dovoljno je da ustane jedan susjed. Takvi ljudi prenose talas dalje.

Visok prag

Ustaje tek kada ustane više susjeda. Ako nijedan susjed ne stoji, na tom mjestu prestaje širenje talasa.

Gdje se to javlja

Stojeći aplauz; pridruživanje protestu ili štrajku (Granovetterov primjer); prihvatanje novog načina rada u grupi.

Sastavni dijelovi

Sala, dva atributa po čovjeku, tri parametra i jedna mjera

Ljudi su nepokretni: svako sjedi na svom mjestu (patch) i posmatra samo svoje susjede.

Ljudi · sjede u sali

  • sala 31 × 31 = 961 mjesto, bez omotavanja (na rubu je manje susjeda)
  • aktivan?: stoji ili sjedi; ko ustane, ostaje stajati
  • moj-prag: najmanji udio susjeda koji stoje potreban za ustajanje, od 0 do 1
ljudi-own [ aktivan? moj-prag ] · sprout-ljudi 1 na svakom patchu
C#: class Covjek : Turtle { bool Aktivan; double MojPrag; }

Pragovi · iz raspodjele

  • prosjek-praga = 0,3
  • rasipanje-praga: koliko se pragovi razlikuju među ljudima; to je standardna devijacija normalne raspodjele (ograničene na 0 do 1). Uz prosjek 0,3 i rasipanje 0,1 oko 95% ljudi ima prag između 0,1 i 0,5; uz rasipanje 0 svi imaju tačno 0,3.
set moj-prag ogranici (random-normal prosjek-praga rasipanje-praga)

Pokretači

  • pokretaci = 10: toliko ljudi ustane na početku, bez obzira na druge
ask n-of pokretaci ljudi [ set aktivan? true ]

Mjera

  • udio-aktivnih: udio ljudi koji stoje
  • model se zaustavlja kada u jednom krugu niko ne ustane
Interakcija

Jedan krug odluke

U svakom krugu svi koji sjede procjenjuju stanje susjeda. Odluke se zasnivaju na stanju s početka kruga.

1 Posmatranje susjeda

Do 8 susjednih mjesta; na rubu sale manje.

let oko-mene ljudi-on neighbors

2 Izračunavanje udjela

Udio susjeda koji stoje.

(count oko-mene with [ aktivan? ]) / (count oko-mene)

3 Poređenje s pragom

Ustane ako je udio susjeda koji stoje barem jednak njegovom pragu.

udio-oko-mene >= moj-prag

4 Zajedničko ustajanje

with izdvaja one koji ustaju; zatim ask izvršava naredbu. Ko ustane u ovom krugu, utiče tek na sljedeći krug.

let ustaju ljudi with [ … ] · ask ustaju [ … ]
Probajte

Numerički primjer odluke

Klikom promijenite stanje susjeda i podesite prag. Prikaz odgovara izračunavanju udio-oko-mene i poređenju s pragom.

Uz 8 susjeda udio raste u koracima od 0,125. Prag 0,3 zato znači „barem 3 od 8“: kada stoje 2 susjeda, udio je samo 0,25. Na rubu sale isti prag znači „barem 2 od 5“.

Misaoni primjer

Isti prosjek praga, različiti ishodi

Primjer iz Granovetterovog rada (1978): dvadeset ljudi, od kojih svako vidi sve ostale. Prag je ovdje broj ljudi koji već stoje: prvi čovjek ustaje sam, drugi kad stoji jedan, treći kad stoje dvojica, i tako dalje.

U početnoj postavci ustane svih 20, jedan za drugim. Ako drugi čovjek ima prag 2 umjesto 1, ustane samo prvi: niko nema prag 1, pa se lanac odmah prekida.

Prosječni prag je u oba slučaja gotovo isti (9,50 i 9,55). Sam prosjek ne određuje ishod; važna je cijela raspodjela pragova.

Veza s modelom

U sali isti mehanizam djeluje lokalno: talas se širi preko ljudi s niskim pragom. Ako ih u blizini pokretača nema dovoljno, talas ne nastaje.

to go
  ① let ustaju ljudi with
    [ not aktivan? and udio-oko-mene >= moj-prag ]
  ② if not any? ustaju [ stop ]
  ask ustaju [
    set aktivan? true
    oboji
  ]
  update-mjere
  tick
end

C# · Blokovi/Blok2Prag.cs
public static bool Go()             // observer: nema this
{
    ① var ustaju = ljudi.With(c => !c.Aktivan
                     && c.UdioOkoMene() >= c.MojPrag);
    ② if (!ustaju.Any()) return false;
    World.Ask(ustaju, c =>
    {
        c.Aktivan = true;
        c.Oboji();
    });
    UpdateMjere();
    World.Tick();
    return true;
}

public double UdioOkoMene()         // metoda klase Covjek
{
    ③ var okoMene = this.PatchHere.Neighbors.TurtlesOn<Covjek>();
    return (double)okoMene.Count(c => c.Aktivan) / okoMene.Count;
}
①with je u C# With(...), koji odmah napravi listu. Lista se napravi prije nego što iko ustane, pa svi u krugu odlučuju prema istom stanju.
②stop u go zaustavlja dugme go. U C# Go vraća false, pa petlja koja ga poziva staje.
③Susjedi su ljudi na susjednim patchevima. U C# je to this.PatchHere.Neighbors: patch na kojem sjedi ovaj čovjek.

Odredite prag i pokretače u pojavi koju modelirate. Pokrenite istu postavku više puta: jedno pokretanje nije dovoljno za procjenu vjerovatnoće talasa.

Zapis bloka u modelu na papiru

Podaci za koje treba navesti izvor

Raspodjela pragova, a ne samo prosjek: udio ljudi u okolini čije je učešće potrebno da bi se čovjek pridružio. Potreban je i broj pokretača.

Zadaci za provjeru

  • Postavite rasipanje na 0,05, pokrenite isti model pet puta (setup, go) i zabilježite broj pokretanja u kojima nastaje talas.
  • Uz rasipanje 0,05 povećajte broj pokretača s 10 na 20 i uporedite rezultate.
  • Postavite prosjek praga na 0,35 i uporedite ishode uz rasipanje 0,1 i 0,2.
