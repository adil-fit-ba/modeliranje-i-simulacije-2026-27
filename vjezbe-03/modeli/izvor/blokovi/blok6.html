Kontrola i kazna

Prekršaj bez kazne povećava sklonost kršenju, a kazna je smanjuje.

Učestalost otkrivanja prekršaja određuje smjer promjene sklonosti. Ispod određenog praga sklonost raste, a iznad njega opada.

Za promjenu slajda koristite strelice ← → ili dugmad pri dnu. Opcija „Čitanje“ prikazuje sve slajdove na jednoj stranici.

Pojava

Iskustvo s prekršajem mijenja sklonost da se prekršaj ponovi

Nakon nekažnjenog prekršaja povećava se sklonost ponavljanju prekršaja, a nakon kazne se smanjuje. Poštivanje pravila ne donosi novo iskustvo.

Prekršaj bez kazne

Sklonost se povećava za mali iznos: + pomak-bez-kazne.

Prekršaj i kazna

Sklonost se smanjuje za veći iznos: − jacina-kazne.

Poštuje pravilo

Nema prekršaja, pa nema ni novog iskustva: sklonost ostaje ista.

Gdje se javlja

Pravila čije se poštivanje povremeno kontroliše: kućni red u zgradi, zabrana pušenja u zatvorenom prostoru, pravila korištenja zajedničkih prostorija. Ljudi uče iz vlastitog iskustva s kontrolom.

Sastavni dijelovi

Jedna vrsta agenata, kontrola kao vjerovatnoća i tri parametra

Ljudi se kreću kao u modelu stava s vježbi 2; razgovor se uključuje prekidačem, kao mediji u tom modelu.

Ljudi · kreću se

  • sklonost od 0 do 1: vjerovatnoća da prekrši pravilo kad ima priliku
  • integritet od 0 (mijenja se najlakše) do 1 (ne mijenja se)
breed [ ljudi covjek ] · ljudi-own [ sklonost integritet prekrsio? kaznjen? ]
C#: class Covjek : Turtle { double Sklonost, Integritet; … }

Kontrola · vjerovatnoća, ne agent

  • vjerovatnoca-kontrole: koliki dio prekršaja bude otkriven (0,1 = jedan od deset)
  • Kontrola se može predstaviti i agentom koji se kreće (inspektor). Izbor je dio oblikovanja modela.
random-float 1 < vjerovatnoca-kontrole

Parametri · klizači

  • jacina-kazne = 0,1: koliko sklonost padne nakon kazne
  • pomak-bez-kazne = 0,02: koliko poraste nakon prekršaja bez kazne
  • razgovor?, domet, uticaj: razgovor kao u modelu stava

Mjere · izlaz modela

  • prosjecna-sklonost svih ljudi
  • udio-prekrsaja u ovoj sedmici i broj-kaznjenih
Interakcija

Dvije odluke pomoću slučajnih brojeva

Svake sedmice svaki čovjek, slučajnim redom (ask ljudi), dobije jednu priliku. Brojevi na granama su vjerovatnoće.

1 Odluka o prekršaju

Izabere se slučajan broj od 0 do 1. Ako je manji od sklonosti, čovjek prekrši pravilo. Sklonost predstavlja vjerovatnoću prekršaja.

if random-float 1 < sklonost [ … ]

2 Otkrivanje prekršaja

Drugi slučajan broj uporedi se s vjerovatnoćom kontrole. Moguća su dva ishoda: kazna ili izostanak kazne.

ifelse random-float 1 < vjerovatnoca-kontrole [ … ] [ … ]

3 Promjena sklonosti

Kazna smanji sklonost više nego što je nekažnjeni prekršaj poveća. Integritet ublažava obje promjene.

max (list 0 …) · min (list 1 …): sklonost ostaje od 0 do 1
Probajte

Očekivana promjena sklonosti u jednoj prilici

Stablo prikazuje vjerovatnoću svake grane i promjenu sklonosti. Opcija „Odigraj priliku“ generiše slučajne brojeve kao random-float 1.

očekivana promjena–
prag kontrole–

Očekivana promjena je zbir proizvoda za sve grane: vjerovatnoća grane × promjena u toj grani. Jednaka je nuli kada je kontrola × kazna = (1 − kontrola) × pomak, tj. kada je kontrola = pomak / (pomak + kazna). Sklonost i integritet mijenjaju brzinu, ali ne i smjer.

Kod

Dva slučajna broja i jedan ifelse

Prikazane su procedura prilika u NetLogu i odgovarajuća metoda u C# (projekat netlogo-kroz-csharp). U C# je uz svaki atribut naveden this. radi jasnog označavanja objekta kojem pripada.

NetLogo · v03-blok6-kazna.nlogox
;; turtle procedura: izvršava je svaki čovjek
to prilika
  set prekrsio? false
  set kaznjen? false
  ① if random-float 1 < sklonost [
    set prekrsio? true
    ② ifelse random-float 1 < vjerovatnoca-kontrole [
      set kaznjen? true
      ③ set sklonost max (list 0
        (sklonost - jacina-kazne * (1 - integritet)))
    ] [
      set sklonost min (list 1
        (sklonost + pomak-bez-kazne * (1 - integritet)))
    ]
  ]
end
C# · Blokovi/Blok6Kazna.cs
public void Prilika()             // metoda klase Covjek
{
    this.Prekrsio = false;
    this.Kaznjen = false;
    ① if (World.RandomFloat(1) < this.Sklonost)
    {
        this.Prekrsio = true;
        ② if (World.RandomFloat(1) < Globals.VjerovatnocaKontrole)
        {
            this.Kaznjen = true;
            ③ this.Sklonost = Math.Max(0, this.Sklonost
                - Globals.JacinaKazne * (1 - this.Integritet));
        }
        else
            this.Sklonost = Math.Min(1, this.Sklonost
                + Globals.PomakBezKazne * (1 - this.Integritet));
    }
}
①Događaj s vjerovatnoćom: slučajan broj od 0 do 1 manji od sklonosti. Isti obrazac služi za svaku vjerovatnoću u modelu.
②ifelse ima dvije grane u uglastim zagradama; u C# je to if … else. Slučajan broj je novi, nezavisan od prvog.
③max (list 0 …) i min (list 1 …) drže sklonost između 0 i 1 (u C# Math.Max, Math.Min). Ta granica malo pomjera prag (slajd 7).
Ishod

Ispod praga kontrole sklonost raste, iznad praga pada

Prosječna sklonost nakon 150 sedmica, za vjerovatnoću kontrole od 0 do 0,5. Na početku je oko 0,5.

Izraz sa slajda 5 daje prag 0,02 / (0,02 + 0,1) ≈ 0,17. U modelu prosjek prelazi početnu vrijednost pri kontroli ≈ 0,16.

Razlika nastaje zbog gornje granice: sklonost ne može preći 1, pa je kod vrijednosti blizu 1 porast ograničen, a pad nije. Zato je prag u modelu nešto niži od izračunatog.

Kontrola 0,1 daje na ticku 150 prosjek 0,67, a kontrola 0,3 daje 0,20. Udaljenost od praga određuje i brzinu promjene: u blizini praga promjena prosjeka je vrlo mala.

Primjena u vlastitom modelu

Definišite kontrolu u pojavi koju modelirate: ko otkriva prekršaje, koliko često i na osnovu kojih izvora se to može utvrditi.

Ishod

Tri puta jača kazna: oko tri puta niži prag kontrole

Prag zavisi od odnosa dobiti od prekršaja i kazne, prema izrazu pomak / (pomak + kazna).

Ista kontrola od 0,1 daje suprotne ishode: uz kaznu 0,1 sklonost raste (medijan 0,67), uz kaznu 0,3 pada (0,23).

Model ne određuje koja je kombinacija bolja u stvarnosti jer ne obuhvata troškove kontrole i kazne. Pokazuje da se njihov uticaj na prag može izračunati i izmjeriti.

Ishod

Razgovor ujednačava sklonosti, a prag ostaje gotovo isti

Uz razgovor? sklonost se približava sklonosti ljudi u blizini, kao stav u modelu s vježbi 2.

Model na papiru

Zapis bloka u modelu na papiru

Model se prvo opisuje na papiru, a zatim u kodu. Blok se zapisuje jednom rečenicom u polju „Interakcije“, uz potrebne atribute i parametre.

Podaci za koje treba navesti izvor

Vjerovatnoća kontrole (udio otkrivenih prekršaja) i omjer kazne i dobiti od prekršaja. Izračunati prag zavisi samo od tih veličina, pa su to dva ključna podatka u modelu.

Pitanje

Odredite kako je kontrola predstavljena u vašem modelu: brojem (kao ovdje), agentom koji se kreće ili mjestom (patch).

Zadaci za provjeru

  • Postavite kontrolu na 0,14, zatim na 0,18 i uporedite smjer promjene sklonosti.
  • Postavite jacina-kazne na 0,3 i odredite vrijednost kontrole pri kojoj se mijenja smjer promjene sklonosti.
  • Postavite pomak-bez-kazne na 0 i ispitajte učinak vrlo male vjerovatnoće kontrole.
  • Uključite razgovor? i analizirajte histogram sklonosti.
