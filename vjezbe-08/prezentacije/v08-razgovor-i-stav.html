16:25–16:33

Pravilo razgovora

A4 §5„Svako domaćinstvo slučajno bira poznanika s iskustvom. Nema li ga, stav se ne mijenja.“
A4 §5„novi stav = stav + (iskustvo sagovornika − stav) × (1 − integritet) × snaga-uticaja“

Predviđanje u chatu
Šta se desi kada je integritet 1? A kada sagovornik ima iskustvo 0?

Novi stav je uvijek između starog stava i iskustva sagovornika, pa ostaje u rasponu 0–1. Sagovornik prenosi iskustvo 0 ili 1, pa prosječan stav može i rasti i padati. U kodu se slajder zove snaga-utjecaja.

16:33–16:46

Razgovor u kodu: dva koraka

A4 §5„Stavovi se računaju iz početnog stanja koraka i primjenjuju istovremeno.“
C# · analogija
if (!razgovor) return;
foreach (var d in domacinstva) {
    d.NoviStav = d.Stav;
    var s = d.Poznanici.Where(p => p.Iskustvo != null).ToList();
    if (s.Count > 0) {
        var p = s[rng.Next(s.Count)];
        d.NoviStav = d.Stav + (p.Iskustvo.Value - d.Stav)
                   * (1 - d.Integritet) * snaga;
    }
}
foreach (var d in domacinstva) d.Stav = d.NoviStav;

Dvije petlje. Prva samo čita stare stavove i puni NoviStav, druga ih prepisuje.

U deklaraciju domacinstva-own dodati novi-stav.

NetLogo · isječak iz v08-razgovor.nlogox
to razgovor
  if not razgovor? [stop]
  ;; 1. korak: svi racunaju novi stav iz stanja na pocetku koraka
  ask domacinstva [
    set novi-stav stav
    let sagovornici link-neighbors with [iskustvo != "nema"]
    if any? sagovornici [
      let sagovornik one-of sagovornici
      set novi-stav stav + ([iskustvo] of sagovornik - stav)
                         * (1 - integritet) * snaga-utjecaja
    ]
  ]
  ;; 2. korak: svi primjenjuju novi stav istovremeno
  ask domacinstva [set stav novi-stav]
end

Zašto ovako

link-neighbors su poznanici. Filtar iskustvo != "nema" izbacuje one koji nikad nisu tražili alat. Prekidač razgovor? isključuje cijeli korak.

Zašto ne drugačije

Uprosječavanje svih poznanika nije pravilo iz A4 (jedan slučajni sagovornik). Bez filtra bi tekst „nema“ ušao u računanje i dao grešku.

16:46–16:48

Zašto istovremeno · misaoni primjer

Lanac A – B – C. Kad bi sagovornik prenosio svoj stav, a ne iskustvo, redoslijed bi bio bitan: ako B promijeni stav prije nego što ga C pita, C bi čuo „novi“ B iz iste sedmice. Ishod bi zavisio od slučajnog reda ask-a.

U našem A4 sagovornik prenosi iskustvo, a iskustvo se u razgovoru ne mijenja. Zato ovdje istovremenost ne mijenja rezultat. Provjerili smo to za seedove 1–20: verzija s jednim ask-om daje isto stanje. Pravilo ipak pišemo u dva koraka, jer je to obrazac za sve modele u kojima se prenosi stav.
